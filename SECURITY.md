# LawyerCMS security

LawyerCMS 0.1.0 is a release candidate. See the [security model](docs/SECURITY.md) and [production release gates](docs/RELEASE_GATES.md) before using real client data.

Please report security issues privately through the maintainer's contact route at https://kwebby.com. Include the version, affected workflow, required role and minimal reproduction using fictional data. Do not attach credentials, client files or database exports to public issues.

No independent penetration test or managed-database certification is claimed. Confirm any fix and its release version before treating a deployment as remediated.
